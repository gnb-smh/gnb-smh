# GnB-SMH: brand and site, v0.1

- `brand-kit/` — logos (SVG, PNG), favicons, social card, colour and type rules. Start with `brand-kit/README.md`.
- `site/` — the static website: `index.html` (GnB-SMH) and `brand.html` (brand guidelines).
  Self-contained: fonts are embedded, no build step. Upload the folder to any static host
  (Cloudflare Pages, GitHub Pages, Netlify) and point the domain at it.
