### CRY-4: what the current evidence establishes

The reviewed [implementation](https://github.com/gnb-smh/gnb-smh/blob/8787ee2967ab49626d965fb5d86d5e18f408c497/node/src/transport/upgrade.rs#L234) initializes HKDF outputs inside `Zeroizing<[u8; 32]>` and moves them through private constructors into stream fields of that type. Both roles retain their previous directions. Public array-taking constructors remain compatible; no dependency, consensus, wallet or WASM change is in that package.

The logs `/private/tmp/gnb-r3-key-ownership-{red,reversal}.log` show real runtime failures in [`derived_keys_require_drop_cleanup`](https://github.com/gnb-smh/gnb-smh/blob/8787ee2967ab49626d965fb5d86d5e18f408c497/node/src/transport/upgrade.rs#L465): actual `(false, false)` against `(true, true)`, with four other tests passing each time.
